# TAE-Workshop: Vorlage

Vorlage für den Praxis-Workshop „Bauen mit einem Coding-Agenten“, TAE Esslingen, 10.11.2026.
Anleitung: https://tae-workshop.netlify.app

1. Oben **Use this template**, dann **Create a new repository**, öffentlich lassen.
2. Im Agenten (Claude Code oder Codex, am Handy oder im Browser) dein neues Repo wählen.
3. Auf der Workshop-Seite Weg „Agent in der Cloud“ und dein Thema wählen und loslegen.

Alle Daten sind erfundene Beispiele. Emissionsfaktoren aus der ÖKOBAUDAT (BMWSB), mit UUID.
